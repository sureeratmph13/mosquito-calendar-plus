# mosquito-calendar-plus

ปฏิทินกันยุงออนไลน์สำหรับหมู่ 5 บ้านจีต ใช้ Google Apps Script และ Google Sheets

## ติดตั้ง

1. สร้าง Google Sheets แล้วเปิด Extensions > Apps Script
2. วาง Code.gs และสร้างไฟล์ HTML ชื่อ Index แล้ววางเนื้อหาจาก Index.html
3. ไปที่ Project Settings > Script Properties เพิ่ม ADMIN_PIN และ STAFF_PASSWORD โดยกำหนดรหัสใหม่ที่ไม่ว่างและแตกต่างกัน เก็บค่าเหล่านี้ใน Apps Script เท่านั้น
4. เรียก setup หนึ่งครั้งเพื่อสร้างแผ่นงานและตั้ง SHEET_ID โดยอัตโนมัติ
5. Deploy เป็น Web app ตามสิทธิ์ที่หน่วยงานกำหนด

## ข้อมูลและความปลอดภัย

- ไม่มีรหัสผ่านจริงหรือฐานข้อมูลรายชื่อบ้านรวมอยู่ใน repository
- เปลี่ยนรหัสเดิมทั้งสองบทบาทก่อนนำรุ่นนี้ไปใช้งาน
- ห้าม commit Script Properties, ข้อมูลส่งออก, รายชื่อบ้าน หรือข้อมูลส่วนบุคคล
- เก็บข้อมูลจริงใน Google Sheets และจำกัดสิทธิ์การเข้าถึงไฟล์
- หน้าบ้านของต้นฉบับใช้เพียงบ้านเลขที่สำหรับอ่านและบันทึกผล จึงยังไม่มีการยืนยันตัวตนรายครัวเรือน ควรประเมินสิทธิ์ผู้ใช้ก่อนเปิดระบบรับข้อมูลจริง
- GitHub เก็บโค้ดเท่านั้น การอัปโหลดนี้ไม่เปลี่ยนแอปที่ deploy อยู่ และ GitHub Pages ไม่สามารถรัน Code.gs ได้

## ไฟล์

- Code.gs: ฝั่งเซิร์ฟเวอร์และการเชื่อม Google Sheets
- Index.html: หน้าผู้ใช้และ dashboard
